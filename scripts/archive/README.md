# 완료된 일회성 데이터 작업

이 디렉터리는 이미 실행한 작업의 기록입니다. 현재 DB 초기화·추가 명령이 아닙니다.
특히 `replace-beginner.mjs`는 과거 400문항 교체의 검증 조건을 유지하므로 현재
492문항 카탈로그에서는 안전하게 중단합니다. 현재 수치에 맞춰 고쳐 재실행하지 마세요.

현재 가져오기는 루트에서 `npm run db:seed`를 사용합니다. 기본 동작은 기존 DB 편집을
보존하고 없는 문항만 추가합니다. 이 구조 정리 작업에서는 DB 변경을 실행하지 않았습니다.

## 오답노트 점검·정리 (루트의 scratch_*.js에서 옮김)
- `check-wrong-answers.cjs`: 미해결 오답 목록을 출력하는 읽기 전용 점검입니다.
- `resolve-reviewed-wrong-answers.cjs`: 복습을 2회 이상 한 미해결 오답을 해결 처리한 일회성 작업입니다.
  DB를 바꾸므로 `--yes` 없이는 실행되지 않습니다.
