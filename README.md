# NihongoQuest

일본어 학습 및 퀴즈 게임 애플리케이션 'NihongoQuest'의 소스 코드 저장소입니다.

## 일본 뉴스 API 설정

1. [The News API](https://www.thenewsapi.com/)에서 무료 API 토큰을 발급합니다.
2. `.env.example`을 참고해 `.env`에 아래 값을 추가합니다.

```env
THE_NEWS_API_TOKEN="발급받은_토큰"
```

환경변수를 추가하거나 변경한 뒤에는 개발 서버를 다시 실행해야 합니다. 토큰이 없거나 외부 API 호출에 실패하면 NHK RSS, 내장 뉴스 순서로 자동 전환됩니다.

뉴스는 한국 시간 기준 하루의 첫 요청에서 최대 40페이지를 조회하고, 중복을 제거한 최신 기사 100건을 PostgreSQL에 저장합니다. 화면에는 저장된 기사 중 무작위 10건을 표시하며 새로고침은 외부 API를 다시 호출하지 않고 10건만 재추첨합니다. 다음 날 수집이 실패하면 기존 뉴스가 삭제되지 않고 그대로 유지됩니다.

## 문제 데이터 동기화

대시보드의 문제 동기화는 기존 사용자, 포인트, 풀이 기록, 오답노트와 단어장을 삭제하지 않습니다. 동일 문제는 기존 ID를 유지하면서 내용을 갱신하고 새 문제만 추가합니다.

현재 N1·초보·모의고사 문제를 함께 동기화하려면 다음 명령을 사용합니다. `.env`의 PostgreSQL에 연결하며, 스테이지가 없으면 생성합니다.

```bash
npm run db:seed
```

현재 가져오기 대상은 N1 연습 384개, 초보 278개, 모의고사 전용 ID 20개로 총 682개입니다. 분류된 기존 문제의 DB 수정 내용과 상태는 기본 동기화가 덮어쓰지 않으며, 과거 문제 행도 삭제하지 않습니다. 개발 환경의 동기화 버튼도 같은 함수를 사용하며, 운영 API는 `SEED_ADMIN_TOKEN` 인증이 필요합니다. 코드 자료로 강제 복원할 때만 `npm run db:seed -- --overwrite`를 사용합니다.

모든 아레나와 모의고사는 **DB의 활성 문제를 조회해 출제·채점**합니다. 코드 데이터는 초기 가져오기와 복구용이며 풀이 중 DB에 덮어쓰지 않습니다. `jlptLevel`, `arenaCategory`, `status`와 유형별 메타데이터로 출제 대상을 관리합니다. DB 스키마 적용은 `npm run db:push`를 사용합니다. [현재 아레나 구조](docs/arena-architecture.md)를 참고하세요.

2026-10-16 구형 N1 6,456개는 별도 백업 후 삭제했고 현재 문제 682개는 유지했습니다. 이 정리는 일반 동기화와 별도이며 초보 문제는 삭제하지 않았습니다.

초보 문제만 직접 동기화하려면 다음 명령을 사용합니다.

~~~bash
npm run db:seed:beginner
~~~

## 앱 설치(PWA)

Chrome·Edge 등에서는 화면 하단의 **앱으로 설치** 버튼을 사용할 수 있습니다. iPhone과 iPad에서는 Safari 공유 메뉴의 **홈 화면에 추가**를 선택합니다.

서비스 워커 설치 기능은 localhost 또는 HTTPS 환경에서 동작합니다. 네트워크가 끊기면 전용 오프라인 안내 화면을 표시하며, API 기반 문제 풀이와 데이터 저장에는 인터넷 연결이 필요합니다.
