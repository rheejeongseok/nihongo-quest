# 현재 아레나 구조

2026-10-20 소스 대조 기준. 아래 수량은 가져오기 카탈로그를 코드로 집계한 결과이며,
현재 운영 DB를 조회한 결과가 아니다. [문서 목차](./README.md)에서 과거 기록을 확인할 수 있다.

## DB가 출제 원본

N1·초보·모의고사 모두 Supabase PostgreSQL의 Quiz를 조회해 출제한다. 일반 아레나 입장과 모의고사 시작은 코드를 통해 문제를 생성하거나 DB에 덮어쓰지 않는다. 문항이 부족하면 오류를 반환하며 코드 자료로 대체하지 않는다.

- N1 일반: `n1Arena.mjs`에서 활성 문제를 유형별로 10개 추출한다. 제출 API가 DB 정답으로 채점한다.
- 초보: `beginnerArena.mjs`에서 DB의 활성 초보 문제를 카테고리·난이도 태그로 조회한다. 네 아레나 각 100개와 문자 입문 92개다. 문자 입문은 난이도 선택이 없다.
- 모의고사: `n1ExamRepository.mjs`에서 DB의 순서대로 20문항을 조회하고 DB 정답으로 채점한다. 종료 시 QuizAttempt를 저장한다.
- 일반 출제·기본 가져오기는 기존 문제 행과 학습 기록을 삭제하지 않는다. 과거 별도 삭제·교체 작업은 보관 기록으로 구분한다.

합계는 N1 1,204 + 초보 492 = 1,696문항 ID다. 문항 수는 독립된 단어·지문 수와 다르다.
모의고사 ID도 일반 연습과 내용이 겹칠 수 있다. DB의 직접 추가·편집·비활성화에 따라
실제 활성 문제 수와 내용은 카탈로그와 달라질 수 있다.

N1은 난이도 선택 없이 시작한다. 초보 네 코스는 EASY(기초)·MEDIUM(기본 응용)·HARD(중급 입문)로
나누며, 코스당 세 난이도 합계 100문항이다. 문자·어휘와 문법은 34·34·32개,
청해와 독해는 36·33·31개다. 공식 JLPT 등급을 인증한 난도 구분은 아니다.
문자 입문은 난이도 선택이 없고 기본 92자만 다룬다. 탁음·요음·촉음·장음은 포함하지 않는다.
같은 회에서 `stimulusId`가 같은 단어·문장·지문·대본은 반복하지 않는다.

초보 일상회화 100개는 별도 소스 콘텐츠이며 Quiz 카탈로그에 포함하지 않는다.
메인에서 중복 없이 5개를 추첨하고 ↻ 버튼으로 다시 뽑는다. [소스 구조](./source-structure.md)를 참고한다.

## Supabase Quiz 관리 필드

| 필드 | 용도 |
| --- | --- |
| jlptLevel | N1, BEGINNER. 구형 미분류는 LEGACY |
| arenaCategory | KANA(초보 문자 입문), VOCAB, GRAMMAR, LISTENING, READING, WORDLE, MOCK_EXAM |
| status | ACTIVE만 출제. ARCHIVED는 기록 보관·출제 제외 |
| itemType | N1 어휘는 reading, context, paraphrase, usage |
| stimulusId | 같은 단어·지문·대화의 공통 키. 일반 아레나 한 회 소재 중복 방지 |
| examOrder | 모의고사에만 1~20의 중복 없는 순서 |
| examDomain | 모의고사 1~9 언어지식, 10~15 독해, 16~20 청해 |

새 문항은 기본 LEGACY·ARCHIVED다. 검수하고 트랙·카테고리·유형·상태를 지정해야 출제된다. 임의의 새 DB ID도 사용할 수 있다. N1 어휘 한 회 비율은 독음 3·문맥 3·바꿔 말하기 2·용법 2, 문법은 선택 6·조립 4다.

모의고사는 현재 20문항 한 회다. 활성 문항 수·순서·영역이 맞아야 시작하며 16~20번은 LISTENING이다. 진행 중 시험에 사용되는 문제·정답은 수정하지 않는 운영이 필요하다.

DB의 실제 활성 N1 자료를 확인할 때 사용할 SQL(이 문서 정리에서는 실행하지 않음):

```sql
select * from "Quiz"
where "jlptLevel" = 'N1' and "status" = 'ACTIVE';
```

## 최초 가져오기·복구

`src/data/n1Quality*.mjs`, `n1Lexicon.mjs`, `beginnerRebuilt*.mjs`, `n1Expansion*.mjs`, `n1Exam.mjs`는 초기 가져오기·복구 자료다. 런타임 출제는 이 파일의 문제를 읽지 않는다.

```sh
npm run db:push
npm run db:seed
```

카탈로그 ID가 없으면 생성한다. 분류된 기존 문제의 DB 편집 내용과 활성 상태는 기본 가져오기가 덮어쓰지 않는다. 카탈로그 ID와 일치하는 미분류 LEGACY 행은 코드 자료로 갱신할 수 있다. Stage 메타데이터는 가져오기 시 갱신한다. 일반 가져오기는 과거 문제를 삭제하지 않는다.

코드 자료로 명시적으로 복원할 때만 `npm run db:seed -- --overwrite`를 사용한다. 이 옵션은 카탈로그 ID의 내용과 상태를 덮어쓴다. 초보만 가져올 때는 `npm run db:seed:beginner`를 사용한다. DB에 직접 추가한 별도 ID의 문제는 제거하지 않는다.

메인 화면에는 가져오기 버튼이 없다. `POST /api/seed`는 같은 기본 가져오기를 수행하며,
production에서는 `SEED_ADMIN_TOKEN`의 Bearer 인증을 검사한다. 개발 환경에서는 토큰 검사를
생략하고, GET은 405로 거절한다. 서버의 일반 출제 요청은 이 API를 호출하지 않는다.

## 과거 DB 작업과 품질 기록

아래는 과거 실행 기록이다. 현재 DB 수량이나 이번 문서 정리에서 실행한 작업을 뜻하지 않는다.

2026-10-16 당시 연결된 Supabase에 필드·인덱스를 추가하고 682개를 등록·활성화했다.
이후 구형 N1 6,456개와 연결된 시도 5개·오답 5개를 백업 후 삭제하고, 당시 N1 404개와
초보 278개를 유지했다. 그 뒤 N1 추가와 초보 교체가 별도로 진행되었다.

삭제는 `scripts/cleanup-legacy-n1.mjs`로 실행했다. 기본 실행은 계획만 출력하며 `--apply`에서만 백업·삭제한다. `.local-backups/`에 문제와 관련 기록을 JSON으로 저장하고 읽기·해시 검증 후 트랜잭션에서 삭제한다. 삭제 전후 남길 Quiz 전체 내용을 비교한다. 이 폴더는 Git에서 제외된다. 동일 스크립트 재실행은 대상이 없으면 삭제하지 않는다.

추가·교체 내역은 [N1 1차](./archive/n1-expansion-20261019.md),
[초보 교체](./archive/beginner-rebuild-20261019.md), [N1 2차](./archive/n1-expansion-batch2-20261019.md)에 보관한다.
초보의 과거 교체·문자 추가 스크립트는 `scripts/archive/`에 있으며 현재 카탈로그로 재실행하지 않는다.

`User`, `Stage`, `Quiz`, `Bookmark`, `WrongAnswer`, `QuizAttempt`, `JapaneseNews`, `NewsRefreshState`는 현재 소스에서 사용한다.
이번 문서 정리에서는 테이블·DB 데이터·Supabase 관리 스키마를 변경하지 않았다.

초기 v3의 [난도 검수](./archive/n1-current-level-audit.md)는 384문항 기준이다.
추가된 800문항 전체에 그 검수 결과를 적용하지 않는다. 자동 검사는 데이터·출제 로직의
무결성을 확인하며 실전 N1 상당 난도나 일본어 전문가 감수를 인증하지 않는다.

## 주소 호환

두 트랙의 문자·어휘는 1, 문법은 3, 청해는 4, 독해는 7이다. N1 워들은 5, 모의고사는 `/mock-exam`이다. 이전 N1 주소 2와 5의 ASSEMBLY는 통합 코스로, 6은 새 모의고사로 연결한다. 초보의 2·5 WORDLE·6은 문자·어휘로, 5 ASSEMBLY는 문법으로 연결한다. 초보 10분 진단은 제거했다. 논리 번호 7 독해는 DB Stage 3에 연결한다.
