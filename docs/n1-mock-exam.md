# N1 모의고사 맛보기

2026-10-20 소스 대조 기준. 고정 20문항 한 회로 시험 진행 방식을 연습하는 기능이다.
문제는 자체 학습 자료이며 최신 기출 복원이나 출제 빈도 예측 자료가 아니다.
현재 데이터 관리 정책은 [아레나 구조](./arena-architecture.md)를 따른다.

## 구성과 진행

| 파트 | 문항 | 제한 시간 |
| --- | --- | --- |
| 1부 언어지식·독해 | 언어지식 9 + 독해 6 = 15 | 20분 |
| 2부 청해 | 5 | 10분 |

`src/lib/examFormat.mjs`가 파트별 문항 수와 시간을 정의한다. 전체 시험 문항 수·배점을
비례 축소한 설계가 아니며, 결과는 정답 수로 표시한다. JLPT 척도 점수나 합격 가능성으로 환산하지 않는다.

- 1부 안에서는 답을 고칠 수 있다. 1부 제출 후에는 되돌아가지 못한다.
- 청해는 순서대로 진행하고 다시 듣기를 허용한다. 브라우저 일본어 음성 합성의 기본 속도는 1.0이다.
- 두 파트가 끝난 뒤에만 서버가 정답과 해설을 반환한다.
- 모의고사 전용 ID를 사용하지만 일부 문항 내용은 일반 연습과 겹친다. 다시 풀면 같은 회차다.

## DB와 진행 상태

`src/lib/n1ExamRepository.mjs`가 DB의 `N1`·`MOCK_EXAM`·`ACTIVE` 문항을
`examOrder` 순으로 읽는다. 20문항의 순서·영역·유형 조건을 검증하며 시작 시 코드 자료를 upsert하지 않는다.
종료 시 DB 정답으로 채점하고 `QuizAttempt` 20건을 기록한다.
같은 응시 ID의 재전송은 같은 시도 ID를 사용하여 중복 저장을 방지한다.

서명 토큰은 사용자 구분·파트 순서·1부 제출 답안·제한 시간을 유지한다.
`src/lib/examSession.mjs`는 `MOCK_EXAM_SECRET`, 미설정이면 `DATABASE_URL`을
용도 분리하여 서명에 사용하고, 개발 환경에서는 둘 다 없을 때 임시 키를 사용한다.
운영에서는 `MOCK_EXAM_SECRET`을 설정하면 DB 연결 정보와 서명 키를 분리할 수 있다.
이 토큰은 모의고사 진행용이며 회원가입·로그인 기능은 아니다.

브라우저 진행 상태는 `sessionStorage`에 보관하며 새로고침해도 서버가 발급한 종료 시각을 사용한다.
진행 중인 시험의 DB 문제·정답을 수정하지 않는 운영이 필요하다.

## 자료와 검수 범위

설계 당시 참고한 공개 자료는 [공식 시험 구성](https://www.jlpt.jp/e/guideline/testsections.html),
[설문 목적 PDF](https://www.jlpt.jp/e/guideline/pdf/n1_e.pdf),
[공식 문제집 안내](https://www.jlpt.jp/samples/sampleindex.html)다.
이번 문서 정리에서는 외부 자료나 실제 기출을 새로 검수하지 않았다.
초기 문항의 난도 검토는 [2026-10-16 검수 기록](./archive/n1-current-level-audit.md)을 참고한다.

파트 잠금·정답 지연 공개·채점·제한 시간·중복 저장 방지는 자동 검사 대상으로 관리한다.
이 검사는 전문가의 일본어 감수, 실제 응시자 정답률·변별력 분석, 사람 화자의 음원 검수를 대신하지 않는다.
