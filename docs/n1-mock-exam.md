# N1 模擬試験・味見版

公開資料から確認できる出題形式と測定対象を反映した固定20問・1回分の自作問題。
未公開の最新問題を復元したものや、直近の出題頻度を統計的に予測したものではない。

- [現行試験構成](https://www.jlpt.jp/e/guideline/testsections.html): N1は言語知識・読解110分、聴解55分。
- [設問の目的](https://www.jlpt.jp/e/guideline/pdf/n1_e.pdf): 読み・文脈・言い換え・用法、形式選択・文構成・文章文法、論理・主張・比較・情報検索、聴解5種。
  このPDFには旧聴解60分の記載が残るため、時間は上の現行ページを優先した。
- [公式問題集案内](https://www.jlpt.jp/samples/sampleindex.html): 公開問題集の提供を確認したが、今回PDF本体は取得できていない。最新の実問題を精査したとは表示しない。

アプリでは20分・15問の言語知識と読解、10分・5問の聴解に縮小。
言語知識9、読解6、聴解5で、約1000字の新規長文と星印の4択文構成、文章文法を含む。
ほかの問題は品質改訂済みプールから固定選出して試験形式に組み直した。
公式の問題数・配点を同率に縮小した試験ではない。

1部の中では答えを直せる。1部提出後は戻れない。聴解は順番に進む。
聴解はブラウザーの日本語音声合成を速度1.0で使い、味見版では聞き直しを認める。
解答と解説は両パートの終了後にのみサーバーから返す。各領域の正答数を示し、
JLPTの尺度得点180点や合否へ換算しない。

開始時にDBのACTIVEなN1・MOCK_EXAMをexamOrder順で20問読み、終了時にDBの正答で採点して20件のQuizAttemptを保存する。開始時に問題をupsertしない。
署名トークンでユーザーとパート順、1部の提出答案、制限時間を保持する。
同一受験IDの再送は同じ試行IDを使い、記録を重複させない。
開発用ランダム鍵以外はMOCK_EXAM_SECRET、未設定ならDATABASE_URLを用途分離して署名に利用。
本番ではMOCK_EXAM_SECRETを設定するとDB接続先変更とセッション署名鍵を分離できる。
ブラウザー内の進行状態はsessionStorageに置き、リロード時もサーバー発行の終了時刻を使う。

これは試験の流れと形式を体験する学習用フォーム。問題難度の専門家校閲、実受験者による
正答率・識別力の分析、人間の話者による音源は未実施。
