# N1 신규 400문항 — 2026-10-19

> 보관 기록: 1차 추가 직후의 수량·DB 작업 기록이다. 아래 합계는 현재 수량이 아니다.
> 최신 코드 카탈로그와 DB 관리 정책은 [아레나 구조](../arena-architecture.md)를 참고한다.

모의고사·워들·초보를 제외한 네 아레나에 새 문항을 100개씩 추가했다.
DB의 Quiz가 실제 출제 원본이며, 추가 자료는 재현 가능한 가져오기용 파일로 남긴다.

| 아레나 | 추가 | 구성 | 추가 후 활성 문항 |
| --- | ---: | --- | ---: |
| 문자·어휘 | 100 | 표제어 25개의 독음·문맥·바꿔 말하기·용법 각 25 | 252 |
| 문법·문장 구성 | 100 | 표현 선택 50 + 조립 50, 원본 문장 50개 | 160 |
| 청해 | 100 | 대화·설명문 20개, 각각 근거가 다른 질문 5개 | 142 |
| 독해 | 100 | 논설·비교·정보 검색 지문 20개, 각각 질문 5개 | 130 |

문항 100개가 서로 다른 표제어 또는 지문 100개라는 뜻은 아니다. 동일 소재의 다른 질문은
stimulusId를 공유하여 한 회 10문항에서는 소재를 중복 출제하지 않는다. 모의고사 20개,
워들 100개, 초보 278개는 추가 대상에서 제외했다.

## 검수와 한계

- 정답과 보기의 중복, 문항 ID·내용의 중복, 조립 조각과 완성문의 일치, 유형별 수량을 검사했다.
- 지문과 질문을 대조하고, 추가 지문의 조건과 정답 근거가 충돌하지 않도록 검토했다.
- 독해에 중문과 장문을 추가하고, 설명을 생략해 의미가 달라지는 사례·조건부 판단·비교를 포함했다.
- 청해는 기존보다 긴 대화와 설명문을 사용하며, 조건 변경·현재 할 일·판단 이유를 구분한다.
- 이는 N1 유형을 목표로 한 자체 학습 자료다. 공식 기출의 복원이 아니며, 전문가 감수나
  실제 수험생 정답률로 실전 N1과 동등한 난도를 확정한 자료는 아니다.
- 자동 검사는 언어적 정답 타당성이나 실제 난도를 인증하지 않는다. 불명확한 문항은 DB에서
  status를 ARCHIVED로 바꿔 출제에서 제외하고 수정할 수 있다.

## 저장

ID 접두사는 `n1-20261019-`다. 기본 동기화로 새 400개만 생성했으며 기존 682개는 갱신하지 않았다.
총 카탈로그는 1,082개(N1 일반·워들 784 + 모의고사 20 + 초보 278)다.
`src/lib/learningData.mjs`에 새 가져오기 자료를 연결했지만, 런타임 아레나는 계속 DB에서 조회한다.
