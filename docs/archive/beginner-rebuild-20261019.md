# 초보 스타터 통합·문제 교체 — 2026-10-19

> 보관 기록: 초보 교체와 문자 입문 추가 당시의 작업 내역이다. N1 수량·전체 합계는 각 작업 시점의 값이다.
> 현재 코스·난이도·출제 규칙은 [아레나 구조](../arena-architecture.md)에 정리했다.
> 아래 `scripts/archive/` 경로는 과거 작업의 증빙이며 현재 가져오기 명령이 아니다.

N1과 같이 문자·어휘, 문법·문장 구성, 청해, 독해 네 아레나로 통합했다.
각 아레나는 총 100문항이며 쉬움(기초)·보통(기본 응용)·어려움(중급 입문)으로 나눈다. JLPT 급수를 확정하는 표시는 제거했다.
각 난이도에 100개씩이 아니라 아레나당 세 난이도 합계 100개다.

| 아레나 | 쉬움 | 보통 | 어려움 | 구성 |
| --- | ---: | ---: | ---: | --- |
| 문자·어휘 | 34 | 34 | 32 | 50개 단어의 독음·문맥 속 의미 각 50 |
| 문법·문장 구성 | 34 | 34 | 32 | 표현 선택 50 + 조립 50 |
| 청해 | 36 | 33 | 31 | 대본 34개에서 서로 다른 질문 총 100개 |
| 독해 | 36 | 33 | 31 | 지문 34개에서 서로 다른 질문 총 100개 |

추가로 `처음 문자 익히기`(KANA, 경로 8)를 가장 앞에 배치했다. 기본 히라가나 46자와
가타카나 46자 총 92문항이며 난이도 선택 없이 10문항을 DB에서 뽑는다. 문자표를 먼저
볼 수 있고, 글자를 보고 로마자 소리를 선택한다. 탁음·요음·촉음·장음은 아직 포함하지 않는다.
초보 전체는 492문항이다. 부담이 큰 어려움 문법 4개와 대응 조립 4개는 생활 표현으로 교체했다.
`scripts/archive/refresh-beginner-kana.mjs`의 일회성 작업으로 기존 문항을 백업한 뒤 8개 갱신·92개 추가했으며
문항 ID와 기존 학습 기록, N1 804개는 유지했다. 전체 출제 경로 5종 × 3개 입력 난이도도 DB에서 검증했다.

모든 코스는 Supabase Quiz에서 BEGINNER·ACTIVE·arenaCategory·난이도 태그로 조회한다.
한 회는 10문항이며 같은 단어·지문·대본을 반복하지 않는다. 어휘는 독음 5 + 의미 5,
문법은 선택 6 + 조립 4로 뽑는다. DB 문제 내용·활성 상태는 일반 출제와 기본 동기화가 덮어쓰지 않는다.

손글씨 연습은 PC 설정·학습 도구와 모바일 학습 도구에 남겼다. 워들·별도 조립·진단 카드는
제거했고, 조립은 문법에 포함했다. 이전 주소 2·5의 WORDLE·6은 문자·어휘로,
5의 ASSEMBLY는 문법으로 연결한다. 기존 N1의 워들·모의고사는 변경하지 않았다.

## 실제 DB 교체

현재 `scripts/archive/replace-beginner.mjs`로 보관한 일회성 작업에서 계획 확인 후 교체했다.
기존 초보 278개, 연결된 시도 3개·오답 2개를 `.local-backups/`에 JSON 백업하고,
검증 후 직렬화 트랜잭션에서 기존 문제 삭제와 새 400개 삽입을 수행했다.
기존 문제의 외래키 삭제에 따라 관련 시도·오답도 삭제되었고 사용자·포인트·단어장은 변경하지 않았다.
N1 문제 804개는 교체 전후 전체 내용을 비교해 보존을 확인했다.

구형 `beginnerQuizzes.mjs` 생성기 대신 `beginnerRebuilt*.mjs`를 사용하므로 동기화로
퇴역한 278개가 다시 생성되지 않는다. 가져오기 카탈로그는 총 1,204개다.

## 검증 범위

문항 수·고유 ID·중복 보기·정답 채점·조립 결합·같은 소재 중복 방지와 4코스×3난이도의 DB
출제를 검사한다. 난이도는 목표 수준이며 공식 JLPT 인증이나 학습자 정답률로 교정한 척도는 아니다.
