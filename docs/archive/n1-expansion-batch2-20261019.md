# N1 2차 추가 400문항 — 2026-10-19

> 보관 기록: 2차 추가 시 수행한 DB 반영·검사 내역이다. 당시 DB 수량을 기록한 것이며 현재 DB의 실시간 집계는 아니다.
> 최신 코드 카탈로그와 DB 관리 정책은 [아레나 구조](../arena-architecture.md)를 참고한다.

모의고사를 제외한 네 아레나에 100문항씩 추가했다. 새 문제는 Supabase Quiz에 저장했고,
일반 출제는 기존 `n1Arena.mjs`의 DB 조회를 통해 사용한다. 워들과 초보는 이번 추가 대상이 아니다.

| 아레나 | 이번 추가 | 구성 | 추가 후 활성 문항 |
| --- | ---: | --- | ---: |
| 문자·어휘 | 100 | 25개 표제어 × 독음·문맥·의미·용법 | 352 |
| 문법·문장 구성 | 100 | 새 문장 50개의 표현 선택·조립 | 260 |
| 청해 | 100 | 새 대화·설명 대본 20개 × 질문 5개 | 242 |
| 독해 | 100 | 새 논설·관점 비교·정보 검색 지문 20개 × 질문 5개 | 230 |

문항 100개는 지문 100개를 뜻하지 않는다. 같은 단어·문장·지문·대본의 문항은 stimulusId를
공유하여 한 회 10문항에서 중복 소재를 피한다. 독해에는 850자 이상 장문 3개를 포함한다.
청해는 앱의 기존 일본어 음성 합성을 사용한다.

## 기준과 검토 범위

[JLPT 공식 문제 구성](https://www.jlpt.jp/guideline/testsections.html)과
[공식 예제 안내](https://www.jlpt.jp/samples/sampleindex.html)를 참고한 자체 연습 자료다.
공식 문제를 복사하거나 기출을 복원한 자료는 아니다. 표현 선택, 논지와 적용 조건,
관점 비교, 정보 검색, 대화 중 제안의 수정과 다음 행동을 묻는다.

정답과 해설을 지문·대본과 대조하고, 의미가 맞을 수 있는 용법 오답과 일부 부자연스러운
선택지를 수정했다. 문항 ID·내용 중복, 사지선다 중복, 조립 조각의 재구성, 엄격 채점,
유형별 개수, 지문 길이, 30개 시드의 출제 비율과 소재 중복 방지를 자동 검사했다.
전체 88개 테스트와 린트를 통과했다. 이러한 검사가 실제 시험 난도나 언어적 완전성을
인증하지는 않는다. 전문가 감수와 수험생 정답률에 의한 난도 보정은 아직 하지 않았다.

## DB 반영

`scripts/import-n1-batch2.mjs` 기본 실행은 읽기 전용 계획 확인, `--apply`는 추가 실행이다.
새 ID 접두사는 `n1-20261019-b2-`다. 직렬화 트랜잭션에서 400개를 생성하고,
기존 1,296개 Quiz 전체 내용이 바뀌지 않았는지 해시로 비교했다. 기존 문항 ID나 학습 기록을
삭제하거나 갱신하지 않았다. 새 400개 저장 내용도 가져오기 자료와 필드별로 비교했다.
실제 DB에서 네 아레나 각각 10개·서로 다른 소재로 조회되는 것을 확인했다.

반영 후 N1은 일반 아레나 1,084 + 워들 100 + 모의고사 20 = 1,204문항이며,
초보 492개를 포함한 전체 Quiz는 1,696개다. 재현 자료는 `n1ExpansionBatch2.mjs`와
`n1Batch2*.mjs`에 있으며, 기본 동기화는 기존 DB 편집 내용을 덮어쓰지 않는다.
