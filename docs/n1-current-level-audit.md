# 현재 N1 아레나 난도 검수 — 2026-10-16

결론: **N1을 목표로 한 유형별 연습 자료다. 일부 표현과 추론은 N1에 근접하지만, 전체를 실전 N1 상당 난도로 보기는 어렵다. 특히 독해 분량·청해 담화·선택지 변별력의 보완이 필요하다.**

## 범위와 판단의 한계

- 실제 출제 경로 `src/lib/n1Arena.mjs`와 활성 데이터 `n1Quality*.mjs`, `n1Exam.mjs`를 검토했다. 보관용 v2 문제와 DB의 과거 문제는 평가에 포함하지 않았다.
- 활성 풀 384문항: 시험형 연습 284문항(문자·어휘 152, 문법·조립 60, 청해 42, 독해 30), 워들 복습 100문항. 모의고사 20문항은 기존 풀 재사용 17개와 전용 문항 3개이므로 384개에 20개를 모두 더하지 않는다.
- 문항 생성 원본의 지문·질문·정답·오답과 실제 샘플링을 정성 검토하고 길이·유형을 Node로 집계했다. 문항별 확정 등급이나 수험생 정답률은 산출하지 않았다.
- [공식 N1 출제 목적·구성 PDF](https://www.jlpt.jp/e/guideline/pdf/n1_e.pdf)를 직접 열어 비교 기준으로 삼았다. [공식 문제집 안내](https://www.jlpt.jp/samples/sampleindex.html)의 검색 결과도 확인했으나, 문제집 본문 PDF와 예제 페이지는 접속 실패했다. **공식 예제 전 문항을 실제로 풀어 일대일 비교한 검수는 아니다.**
- 공식 자료는 개별 단어·문법의 N1 소속이나 현재 문제의 난도를 인증하지 않는다. 아래 ‘근접’은 표현·담화·추론에 관한 검수 판단이다. 실제 응시자 데이터와 일본어 전문가의 검토가 추가로 필요하다.
- 이번 작업은 평가 기록이며 출제 데이터나 운영 DB를 수정하지 않았다.

## 구체적으로 확인한 항목

1. **정답 타당성 오류 — 端緒 독음**
   - 정답 `たんしょ`, 오답 `たんちょ／だんしょ／たんしゅ`로 설정되어 있다.
   - 小学館デジタル大辞泉은 `たんちょ`도 관용 독음으로 수록한다. 이를 단일 정답 문제의 오답으로 두면 허용 독음을 틀렸다고 가르친다. 오답을 바꾸고 해설에 두 독음을 안내해야 한다.
   - 근거: [デジタル大辞泉・端緒（コトバンク 제공）](https://kotobank.jp/word/%E7%AB%AF%E7%B7%92-564148).
2. **독음 선택지 변별력 — 均衡**
   - 오답 `きんこうう`처럼 길이를 기계적으로 늘린 형태가 포함된다. 근접 발음 오답도 있지만, 모든 보기가 실제 학습자가 혼동할 법한 형태인지는 재검토해야 한다.
3. **정답 의미를 미리 설명하는 문맥 — gramnotimpossible-choice**
   - 앞 문장에 `不可能ではない`를 제시하고 `できないわけではない`를 고르게 한다. 제한적 긍정의 학습에는 좋지만, 정답 의미를 스스로 추론하는 부담은 낮다.
4. **용법 오답이 지나치게 어색함 — 妥結**
   - 정답은 교섭이 타결되는 문장이고, 오답은 자료·제품 사양·예산을 `妥結`하는 문장이다. 표제어의 대표 결합만 알아도 세 보기를 쉽게 지울 수 있다. 자연스럽고 비슷한 업무 문맥 속 용법 차이를 다루도록 재작성할 필요가 있다.
5. **즉시 응답이 노골적인 반대로 구성됨 — responseinvitation-reply**
   - 참석 불가 발언에 오답 3개가 모두 참석 확정·담당 배정 방향이다. 완곡한 거절을 알아듣는 연습은 되지만, 세밀한 태도·화행을 구별하는 변별력은 제한적이다.
6. **읽지 않고 선택지의 태도만 고를 위험**
   - 독해의 여러 지문이 ‘장점 인정 → 무조건 적용 부정 → 조건과 한계를 검토’ 구조다. 정답은 균형적이고 오답은 `全て／必ず／だけ`처럼 극단적인 경우가 반복된다. 새로운 주제·논지 구조와 부분적으로 참인 근접 오답을 늘려야 한다.
7. **모의고사의 앞선 학습 노출 영향**
   - 17문항이 일반 아레나의 문항과 같다. 맛보기 기능에는 허용할 수 있지만, 이미 본 문항의 정답률로 실전 능력을 추정하면 과대평가할 수 있다.

## 보완 순서

1. 허용 독음을 오답으로 넣은 항목과 복수 정답·부자연스러운 일본어를 먼저 감수한다.
2. 독해에 약 500자 중문, 약 1,000자 장문, 충분한 분량의 A/B·자료 검색 지문을 추가한다. 단순한 문장 늘리기보다 논지 전개와 근거 추적을 설계한다.
3. 청해에 긴 독백·뉴스·강의, 여러 제안의 수정과 정보 통합을 추가하고 실제 재생 음성을 별도로 검수한다.
4. 정답의 뜻을 그대로 풀어 준 선행 문장을 줄이고, 자연스러운 근접 오답으로 재작성한다. 극단적 오답만으로 답을 찾는 패턴도 줄인다.
5. 일반 문법에 글의 문법 유형을 추가하고, 모의고사는 가능한 한 전용 문항으로 분리한다.
6. 실제 사용자 정답률·보기별 선택률을 모아, 너무 쉬운 문제와 정답이 모호한 문제를 구분해 재조정한다.

이번 검수로 ‘몇 %가 N1’이라는 수치는 제시하지 않는다. 공식적으로 교정된 문항 척도와 응시자 통계 없이 정밀한 비율을 붙이면 근거 이상의 확신을 주게 된다.

## 후속 정답 오류 수정 — 2026-10-16

- `端緒` 독음 문항에서 허용 독음 `たんちょ`를 오답에서 제거하고, 해설에 관용 독음임을 명시했다.
- `融通`에서도 사전에 등재된 `ゆずう`를 오답에서 제거했다. 문맥에 맞는 일반 독음은 `ゆうずう`로 유지하고 해설에 이독을 안내했다. 근거: [小学館デジタル大辞泉・融通](https://kotobank.jp/word/%E8%9E%8D%E9%80%9A-650828).
- 두 항목의 허용 독음이 오답에 재진입하지 않는 회귀 검사를 추가했다. 전체 테스트 79개와 ESLint 통과.
- 수정한 활성 원본은 다음 출제 시 DB upsert로 반영된다. 기존 시도 기록·오답 기록을 소급 수정하지 않았고 운영 DB 일괄 갱신도 수행하지 않았다. 이미 열린 문제는 새로 시작해야 새 보기를 받는다.
- 이는 확인된 오류 2건의 수정이며 전체 문항의 정답 타당성에 대한 전문가 인증을 뜻하지 않는다.
