## 갱신 기준

- 현재 동작과 명령은 현재 안내에 갱신하고, 완료된 교체·검수 결과는 날짜와 범위를 붙여 보관한다.
- 코드 카탈로그 수량과 실제 DB 활성 문항 수를 구분한다. DB 편집·비활성화·직접 추가에 따라 둘은 다를 수 있다.
- 자동 검사 통과와 실전 난도·일본어 전문가 감수는 구분한다.
- DB를 변경하는 명령은 일반 출제나 화면 새로고침과 구분해 설명한다.
