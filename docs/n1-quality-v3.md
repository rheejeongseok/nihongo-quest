# N1 통합 코스와 문제 품질 개편

기준: [공식 시험 구성](https://www.jlpt.jp/e/guideline/testsections.html),
[공식 N1 능력 기준](https://www.jlpt.jp/e/about/levelsummary.html).
공식 기출을 복제하거나 통계적 난도를 인증한 자료가 아닌 자체 학습 자료다.

## 현재 출제 풀

| 코스 | 활성 문항 | 구성 |
| --- | ---: | --- |
| 문자·어휘 | 152 | 독음 93, 문맥 20, 바꿔 말하기 29, 용법 10 |
| 문법·문장 구성 | 60 | 문맥에 따른 표현 선택 30, 5조각 이상 문장 조립 30 |
| 청해 | 42 | 다화자 대화 16개의 질문 32, 즉시 응답 10 |
| 독해 | 30 | 논리·필자 의도, 두 글 비교, 안내문·조건 검색: 15지문의 질문 30 |
| 어휘 워들 복습 | 100 | 어휘 코스 안의 별도 복습 버튼 |
| 합계 | 384 | 평가형 연습 284 + 워들 복습 100 |

동일 단어를 독음·문맥·용법 등에서 재사용하는 경우가 있다. 서로 다른 질문 유형의
문항 수이며, 전부 다른 단어·지문 384개라는 뜻은 아니다.
기존 740문항과 가상 조립 100문항의 생성 소스는 제거했다. 기존 DB 행과 학습 기록은 유지한다.
기존 DB의 N1 태그 전체를 읽어 합치지 않으므로 이전의 낮은 품질 문항이 재유입되지 않는다.
자료를 늘리기 전에 오답 설계와 정답 근거를 정비하는 것을 우선했다.

## 바뀐 품질 기준

- 독음: 다른 단어의 독음을 순환해 가져오지 않고 각 단어의 유사 독음 보기를 지정했다.
  정답이 이미 적혀 있는 순수 히라가나 표제어는 독음 문제에서 제외했다.
- 문맥·용법: 각 문제에 맞춰 보기를 작성한다. 의미가 가까워 중복 정답이 될 수 있는
  표현은 같은 빈칸의 오답으로 쓰지 않고 바꿔 말하기 문제 등으로 구분한다.
- 문법: 앞뒤 맥락과 대비·양보·이유·부정 범위 등을 근거로 답을 고르게 한다.
  조립은 짧은 두 조각 대신 5조각 이상으로 구성한다.
- 청해: 별도의 질문·오답·근거를 작성한다. 행동 오답에 문구를 붙여 이유·개요
  오답으로 재활용하던 방식을 제거했다. N1 재생 기본 속도는 1.0이다.
- 독해: 별도 지문 패널과 문맥 근거를 제공한다. 두 글의 공통점·차이와 정보 검색을 포함한다.
- 같은 세션에서는 동일 단어·대화·지문의 다른 질문을 반복하지 않는다.
  학습 중 다른 문항의 답이 먼저 노출되는 것도 방지한다.
- 새 객관식·청해·독해는 저장된 정답만 인정한다. 제시문 자체는 정답으로 인정하지 않는다.
- 정답 공개 전 어휘 독음·조립 정답을 음성으로 들을 수 없게 한다.

## 출제와 주소

문자·어휘 10문항: 독음 3 + 문맥 3 + 바꿔 말하기 2 + 용법 2.
문법·문장 구성 10문항: 표현 선택 6 + 조립 4.
청해·독해·워들: 각 10문항.
모의고사 맛보기: 언어지식 9 + 독해 6 + 청해 5, 20문항·30분.
기존 15분 종합 연습은 제거했다. 공식 시험의 전체 문항 수·시간·배점을 재현하는 완전한 모의시험은 아니다.

| 이전/현재 주소 | 현재 동작 |
| --- | --- |
| `/play/1`, `/play/2`의 N1 | 문자·어휘 통합 |
| `/play/3`, `/play/5?category=ASSEMBLY`의 N1 | 문법·문장 구성 통합 |
| `/play/4`의 N1 | 청해 |
| `/play/7`의 N1 | 독해 |
| `/play/5?category=WORDLE`의 N1 | 어휘 워들 복습 |
| `/play/6`의 N1 | `/mock-exam`으로 이동 |
| `/mock-exam` | 모의고사 맛보기 |

현재 문제를 DB로 가져온 뒤 `jlptLevel=N1`, `status=ACTIVE`, `arenaCategory`로 조회한다.
코드 자료는 최초 가져오기용이며 출제 때 DB에 덮어쓰지 않는다. 독해의 논리적 코스 번호 7은 기존 Stage 3을 사용한다.
출제 메타데이터 필드를 추가했으며 기존 문제·오답 기록은 삭제하지 않았다. 상세한 관리 방법은 [현재 구조](./arena-architecture.md)를 참고한다.
초보 스타터의 코스·문제·난이도와 기존 손글씨 채점은 유지한다.

## 검증 범위와 남은 한계

전 문항 ID·보기 중복·정답·해설·조립 결합을 자동 검사하고 40개 무작위 시드에서
유형 비율·같은 소재 중복 방지를 확인한다. PC·모바일 메뉴와 독해 답안 제출·해설도
브라우저에서 확인한다. 이 검사는 실제 수험생의 정답률이나 일본어 전문 감수를
대신하지 않는다. 중장문 독해의 확장과 음원 감수, 문항별 응답 통계는 후속 품질 개선 대상이다.
