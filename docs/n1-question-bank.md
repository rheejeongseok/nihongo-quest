# N1 연습문제 구성

> 아래는 이전 v2 자료 740개의 보관용 설명이다. 현재 출제 풀과 통합 코스는
> [v3 개편 문서](./n1-quality-v3.md)를 따른다.

공식 JLPT의 [시험 구성](https://www.jlpt.jp/e/guideline/testsections.html)과
[공식 예제 안내](https://www.jlpt.jp/e/samples/sample09.html)를 참고해 직접 작성한 연습문제다.
공식 기출 복제본이나 실제 출제 빈도 통계가 아니다. 워들은 시험 유형이 아닌 어휘 복습 기능이다.
전체 문항의 실전 N1 난도를 보장하지 않는다. 현재 난도와 오답 설계의 한계는
[수준 점검 결과](./n1-level-audit.md)를 참고한다.

| 아레나 | 신규 문항 | 구성 |
| --- | ---: | --- |
| 문자 | 100 | 문맥 속 한자 독음 |
| 어휘 | 220 | 문맥 규정 100, 바꿔 말하기 100, 용법 20 |
| 문법 | 110 | 문법 표현 선택 100, 문단 연결·문맥 10 |
| 청해 | 110 | 30개 상황의 과제·요점·개요 90, 즉시 응답 20 |
| 워들 | 100 | 의미를 단서로 어휘 완성 |
| 문장 조립 | 100 | 50개 표현을 두 문맥에서 조립 |
| 합계 | 740 | 난이도별 복제 없이 집계 |

기존 문장 조립 100개는 안정적인 ID와 함께 별도 파일에 보존한다.
모의고사는 문자·어휘·문법·청해·문장 조립에서 각 3개씩, 총 15개를 추출한다.
청해는 브라우저의 일본어 음성 합성을 사용하며 실제 시험 녹음 음원이 아니다.

N1은 난이도를 구분하지 않는다. 이전 URL에 남은 difficulty는 무시한다.
초보 스타터의 EASY/MEDIUM/HARD 구분은 유지한다.

신규 문제는 서버의 버전 관리된 문제 풀에서 즉시 출제한다. 선택한 문항만 DB에 upsert하여
제출 API가 서버의 정답으로 채점할 수 있게 한다. 전체 seed 동기화에도 신규 문제가 포함된다.
기존 N1 DB 문제와 합칠 때 난이도 메타 태그를 제거한 내용으로 중복을 판정한다.
문제 행을 삭제하지 않으므로 기존 풀이·오답 기록의 참조는 유지된다.

검증: `npm test`, `npm run lint`, `node node_modules/next/dist/bin/next build`.
빌드한 서버를 3102 포트로 실행하면 `node scripts/check-arena-ui.mjs`로 Chrome 화면 검증도 가능하다.
이 화면 검증은 사용자·퀴즈 API를 테스트 응답으로 대체하여 학습 기록을 쓰지 않는다.
